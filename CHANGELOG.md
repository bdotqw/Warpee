# Warpee

## 13.2

ENG

**Retail / Forever**

- The addon no longer draws a countdown of its own on a cooldown; the client's own number is restyled instead. It was the addon's own text that made the timer disappear.
- The bag-slots button in the bags header now reads "bag slots" instead of "Bags".

**Forever**

- A new bank-slots button in the bank header.
- Cooldowns are no longer drawn on items that cannot be used.

RU

**Retail / Форель**

- Больше не рисуется свой текст кд на вещах, а стилизуется близзардовский: именно из-за своей цифры пропадал таймер кд.
- Кнопка ячеек для сумок в шапке сумок теперь «ячейки для сумок» вместо «сумки».

**Форель**

- Новая кнопка ячеек банка в шапке банка.
- Кулдауны больше не рисуются на предметах, которые нельзя использовать.
